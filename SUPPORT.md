# Support

## Bugs

Use GitHub Issues with the bug report template. Include the package/version,
browser, framework, reproduction, expected behavior, actual behavior, and
whether multiple tabs are involved. Do not include credentials or private
request bodies.

## Questions

Use GitHub Discussions for usage questions once the public API is available.

## Security

Use the private reporting process described in [SECURITY.md](SECURITY.md), not
a public issue.

## Feature requests

Use the feature request template and explain the problem, proposed API,
alternatives, and why the feature belongs in OfflineQ.
